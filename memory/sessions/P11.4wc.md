### ⚠️ 재발방지 체크리스트 (필수)

#### 1. GitHub Pages 깨짐 방지
- `deploy.yml`의 `VITE_BASE_PATH`가 **레포 이름과 일치**하는지 확인: 현재 `marklink-sl`
- 새 기능 추가 후 반드시 `npx vite build` 성공을 확인한 뒤 커밋
- 레포 이름이 변경되면 즉시 `deploy.yml`도 갱신

#### 2. 중복 코드 방지 (컨텍스트 압축 후 특히 주의)
- **새 함수/변수 추가 전**: `grep -n "function 함수명"` 으로 기존 존재 여부 확인
- **새 let/const 추가 전**: `grep -n "let 변수명\|const 변수명"` 으로 기존 선언 확인
- 이번 세션에서 중복 발생한 함수들: `showNamedRangesDialog`, `showPivotTableDialog`, `showDataValidationDialog`, `namedRanges`, `dataValidations`
- **빌드 실패 시**: 에러 메시지의 "already been declared" 패턴 = 중복 선언 → 나중에 추가된 것을 삭제

#### 3. 기능 추가 작업 흐름
1. 추가할 기능의 함수명 결정
2. `grep`으로 기존 코드에 동일/유사 함수 존재 여부 확인
3. 없으면 구현, 있으면 기존 코드 확장
4. `npx vite build` 성공 확인
5. 커밋 + 푸시
