## 핵심 결정사항
- SVG data: URI는 스크립트 실행 위험으로 계속 차단
- DOC 서식은 Piece Table + simple PRM(bold/italic)까지만 — 전체 CHP 파싱은 과도
- PPT 레코드 트리 파싱 실패 시 기존 바이트 스캔으로 폴백
- XLSX는 이미 formulas/styles/merges 전부 반영 중 — 추가 작업 불필요
- ODS는 SheetJS가 네이티브 처리하므로 별도 파서 불필요

## 총평

### 이번 세션의 의의
P11.46wc에서 "열리기만 하는" 수준이었던 레거시 바이너리 포맷(HWP/DOC/PPT)을 **서식·이미지·테이블 구조까지 반영하는 수준**으로 끌어올렸다. 특히 HWP 바이너리는 한국 사용자 핵심 포맷이므로, 문단 정렬/여백/줄간격 + 셀 병합 + 임베디드 이미지까지 지원하게 된 것이 큰 진전. 또한 전체 14개 파일 포맷의 임포트 경로를 전수 감사하여 숨어있던 이슈 4건을 발굴·수정했다.
