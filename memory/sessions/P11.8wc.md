# P11.8wc — OfficeLink SL Phase 8 (PDF Viewer Enhancement)

## 메타데이터
- 생성: 2026-03-22
- 포크원: P11.7wc
- 자식: 없음

## 작업 요약
PDF Viewer를 Adobe Acrobat 수준으로 향상. 페이지 관리(재정렬/삭제/삽입/추출),
주석 도구(하이라이트/밑줄/취소선/스티키노트/프리핸드), 페이지 회전,
Deskew(기울기 자동 보정), 텍스트 선택 및 검색 기능 구현.

## 주요 결과물
- `index.html` — PDF 툴바에 17개 신규 버튼/컨트롤 추가, 썸네일 사이드바 레이아웃
- `src/pdf/pdf-viewer.js` — 전체 재작성: 페이지 관리, 주석, 회전, deskew, 검색 엔진
- `src/styles/pdf.css` — 썸네일, 주석 레이어, 검색 하이라이트, 스티키노트 등 스타일

## 핵심 결정사항
- 페이지 재정렬은 썸네일 드래그앤드롭으로 구현 (pageOrder 배열 관리)
- Deskew는 수평 projection profile + variance 기반 각도 검출
- 주석은 별도 canvas 레이어로 오버레이 (원본 PDF 비파괴)
- 텍스트 선택은 PDF.js getTextContent → span 기반 text layer
- 페이지 추출은 PNG 다운로드 방식 (순수 클라이언트사이드)
