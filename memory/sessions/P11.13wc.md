# P11.13wc — Markdown Editor Enhancement (Preview/KaTeX/Mermaid/TOC/Export)

## 메타데이터
- 생성: 2026-03-22
- 포크원: P11.12wc
- 자식: 없음

## 작업 요약
Markdown 에디터에 5가지 핵심 기능 추가:
1. Live Preview Toggle (show/hide 버튼)
2. Math 렌더링 (KaTeX - 이미 설치됨, 툴바 삽입 버튼 추가)
3. Mermaid 다이어그램 (이미 설치됨, 툴바 삽입 버튼 추가)
4. Outline/TOC 패널 (자동 생성 목차, 클릭 점프)
5. Export 옵션 (Copy as Rich Text 추가)

## 주요 결과물
- `index.html` — TOC 패널 HTML, 새 툴바 버튼들 (Math, Mermaid, Preview Toggle, Outline, Copy Rich Text)
- `src/styles/editor.css` — Outline 패널 스타일, Preview toggle 상태, Toast 알림
- `src/ui/toolbar.js` — Math inline/block, Mermaid 삽입 바인딩
- `src/preview/renderer.js` — Heading anchor ID 자동 부여 (TOC 점프용)
- `src/app.js` — Outline 패널 로직, Preview toggle, Copy as Rich Text, Export 메뉴 확장

## 핵심 결정사항
- marked.js 대신 기존 markdown-it 유지 (이미 KaTeX/Mermaid 플러그인 설정됨)
- KaTeX는 `@mdit/plugin-katex`로 이미 등록되어 있으므로 추가 설치 불필요
- Mermaid는 npm 패키지로 이미 설치됨 (preview.js에서 dynamic import)
- TOC는 에디터 텍스트에서 직접 파싱하여 생성 (코드 블록 내 heading 제외)
