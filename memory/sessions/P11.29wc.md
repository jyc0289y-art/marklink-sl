# P11.29wc — PDF/Slide Enhancement (Viewer & Editor)
## 메타데이터
- 생성: 2026-03-24
- 포크원: P11.28wc
- 자식: 없음

## 작업 요약
PDF viewer와 Slide editor에 대한 대규모 기능 강화 세션.
PDF: go-to-page, fit-to-page/actual-size 줌, 키보드 네비게이션(좌우 화살표, Home/End), 색상별 스티키노트, 프리핸드 색상/두께 옵션.
Slide: 노트 패널 리사이즈, 프레젠테이션 펜 캔버스 리사이즈 버그 수정.

## 주요 결과물
- `index.html` — PDF 툴바에 go-to-page 입력, fit-page/actual-size 버튼, 스티키노트 색상 선택, 프리핸드 색상/두께 추가. 슬라이드 노트 리사이즈 핸들 추가.
- `src/pdf/pdf-viewer.js` — go-to-page, fitPage(), 키보드 네비게이션 확장, 색상 스티키노트, 프리핸드 색상/두께 지원
- `src/styles/pdf.css` — goto-input 스타일, 스티키 팝업 헤더/닫기 버튼 스타일
- `src/styles/slide.css` — 노트 리사이즈 핸들 스타일, 노트 영역 min/max-height
- `src/slide/slide-editor.js` — 노트 패널 드래그 리사이즈, 프레젠테이션 펜 캔버스 window resize 리스너

## 핵심 결정사항
- PDF 키보드 네비게이션: input/textarea에 포커스가 있을 때는 무시
- 스티키노트: 6가지 색상(Yellow/Green/Blue/Orange/Pink/Purple), 닫기 버튼으로 삭제 가능
- 노트 리사이즈: 40px ~ 400px 범위, mousedown + mousemove 방식
