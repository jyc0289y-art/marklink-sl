## 작업 요약
바이너리 HWP 파일을 포함한 레거시 오피스 포맷(DOC, PPT, XLS)의 파일 열기 기능을 구현. OLE2 Compound File 파서를 직접 구현하여 브라우저에서 바이너리 HWP/DOC를 파싱하고, PPT는 텍스트 아톰 스캔 방식으로 내용 추출. XLS는 SheetJS가 이미 지원하나 파일 피커에서 제한하고 있던 것을 해제.

## 주요 결과물
- `src/document/hwp-binary.js` — OLE2 파서 + HWP 바이너리 레코드 → HTML 변환 (텍스트/서식/표)
- `src/document/doc-legacy.js` — Word 97-2003 DOC 텍스트 추출
- `src/slide/slide-file.js` — PPT TextCharsAtom/TextBytesAtom 스캔 → 슬라이드 변환
- `src/sheet/sheet-file.js` — XLS 피커 추가
- `src/file/drag-drop.js` — .hwp/.doc 드래그앤드롭 라우팅
- `src/ui/offline-manager.js` — 네트워크 전환 시 null 참조 버그 수정
- `tests/hwp-binary.test.js` — 37개 신규 테스트
- 커밋: faa2b42, push 완료

## 핵심 결정사항
1. OLE2 파서를 외부 라이브러리 없이 순수 JS로 구현 (FAT/DIFAT/MiniStream 포함)
2. HWP 바이너리의 zlib 해제에 DecompressionStream API 사용 (모던 브라우저 네이티브)
3. 레거시 DOC/PPT는 완전한 서식 보존보다 텍스트 추출 우선 — 서식이 필요하면 DOCX/PPTX로 변환 권고
4. XLS는 SheetJS가 이미 완전 지원하므로 피커 확장만으로 해결
