# P11.33wc — Print Preview & Drag-Drop Enhancement
## 메타데이터
- 생성: 2026-03-25
- 포크원: P11.30wc
- 자식: 없음

## 작업 요약
Print preview modal, enhanced drag & drop overlay, clipboard paste improvements, and @media print CSS rules.

## 주요 결과물
- `src/export/print.js` — Full print preview modal with page size/orientation/margin controls
- `src/file/drag-drop.js` — Enhanced drop zone with file type icons, multi-file, image-into-document support
- `src/document/doc-editor.js` — Image paste from clipboard, TSV paste as table
- `src/photo/photo-editor.js` — Clipboard image paste support
- `src/styles/main.css` — Print preview modal CSS, enhanced drop overlay CSS, @media print rules
- `index.html` — Updated drop overlay markup with file type indicators

## 핵심 결정사항
- printDocument() now opens print preview modal instead of direct printing (backward compatible API)
- PDF tab passes through to browser print directly
- Multi-file drop opens first file, shows toast for remaining
- Drop on document editor inserts images at cursor
- @media print hides all chrome (toolbar, sidebar, tabs, status bar)
