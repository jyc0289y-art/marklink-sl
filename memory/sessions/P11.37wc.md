## 작업 요약
OfficeLink SL의 마크다운 프리뷰, 슬라이드 에디터, 문서 에디터에 걸친 프레젠테이션/미리보기 기능 강화.
3개 파트로 나뉘어 진행: (1) 마크다운 양방향 스크롤 싱크+줌+프레젠테이션, (2) 슬라이드 프레젠터뷰/정렬뷰/전환효과 미리보기, (3) 문서 읽기모드+TOC 패널.

## 주요 결과물
- `src/preview/preview.js` — 양방향 스크롤 싱크, 줌 컨트롤(50-150%), 마크다운 프레젠테이션 모드, 프리뷰 툴바
- `src/app.js` — 새 프리뷰 import 및 bidirectional sync 연결
- `src/slide/slide-editor.js` — 프레젠터뷰에 시계 추가, 슬라이드 정렬뷰에 다중선택/우클릭 컨텍스트 메뉴/삭제, 전환효과 호버 미리보기
- `src/document/doc-editor.js` — 읽기모드에 TOC 패널 추가(중첩 목록, 현재 섹션 하이라이트), Ctrl+Shift+R 단축키

## 핵심 결정사항
- 기존 app.js의 단방향 scrollSync를 양방향으로 교체 (preview.js에서 export)
- slide-editor.js의 기존 showEnhancedSlideSorter 중복 함수명 충돌을 showEnhancedSorterContextMenu로 리네임하여 해결
- 읽기모드 TOC는 사이드바 형태로 구현, 스크롤 시 현재 섹션 자동 하이라이트
