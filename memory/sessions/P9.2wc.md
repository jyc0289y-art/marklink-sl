## 작업 요약
HWPX 파일 포맷에 대한 기술 리서치. KS X 6101 (OWPML) 표준 기반 여부, 라이선스 상태,
ZIP/XML 구조, 오픈소스 JS/TS 라이브러리 조사. MarkLink SL에 HWPX 지원 추가 가능성 평가.

## 주요 결과물
- HWPX 포맷 리서치 결과 (세션 대화 내)

## 핵심 결정사항
- HWPX는 KS X 6101 (OWPML) 한국 국가표준 기반 → 공개 표준
- ZIP + XML 구조로 구현 가능
- MIT 라이선스 JS 라이브러리 존재 (@ssabrojs/hwpxjs)
- AGPL 주의 필요 (hwpx-ts)
