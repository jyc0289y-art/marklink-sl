## 핵심 결정사항
1. **Analytics**: Plausible/GoatCounter 대신 GA4 선택 (무료, 상업적 사용 가능)
2. **HWPX**: AGPL hwpx-ts 대신 JSZip(MIT) + 자체 파서 구현 (라이센스 안전)
3. **Sheet 수식**: 자체 구현 (외부 라이브러리 없이 SUM/AVERAGE/COUNT/MIN/MAX/IF 지원)
4. **모든 라이브러리 라이센스 검증**: JSZip(MIT), SheetJS(Apache 2.0), PDF.js(Apache 2.0)
5. **포트**: 개발 서버 5180 사용 (PhotoLink과 충돌 방지)
6. **기본 언어를 영어로 변경** — 글로벌 서비스이므로 영어 기본, IP/브라우저 감지로 추천
7. **기본 뷰를 Document(Word)로 변경** — 첫 사용자 친화성
8. **탭 순서: Document > Sheet > Slide > PDF > Markdown** — Markdown을 마지막으로
9. **34개 언어** — 동남아/아프리카/남아시아 등 구매력 낮은 국가 언어 포함
10. **온보딩 투어 6단계** — 언어 → 탭 → AI → 파일열기 → 내보내기 → 튜토리얼 버튼

## 다음 작업을 위한 컨텍스트

### 해결해야 할 과제
1. **PhotoLink 통합** — PhotoLink(웹 사진 편집기, P13)를 MarkLink SL에 통합하여 이미지 편집 기능 제공. Document/Slide 내 이미지 직접 편집 가능하도록.
2. **공학용 계산기 기능 추가** — Sheet 탭 또는 별도 탭으로 공학용 계산기(과학 함수, 단위 변환, 그래프 등) 제공. 무료 오피스 대안으로서의 경쟁력 강화.
3. **온보딩 투어 개선 (UX)**:
   - 현재 투어가 툴바 우측 → 탭바 → 다시 우측 → 다시 좌측 → 우측으로 동선이 왔다갔다해서 시선이 분산됨. **좌→우 또는 상→하 자연스러운 동선**으로 재정렬 필요.
   - **오피스 주요 기능 전체에 툴팁 투어 추가**: Document 편집(B/I/U, 폰트, 정렬), Sheet(수식 입력, 셀 선택), Slide(레이아웃, 프레젠테이션 모드), PDF(열기, 변환), AI(컨텍스트 버튼, 세션 관리) 등 각 탭별 핵심 기능을 포함하는 확장 투어.
   - **"다시 보지 않기" 버그 점검**: 현재 ❓ 튜토리얼 버튼 클릭 시 `localStorage.removeItem('marklink-tour-done')` 후 `startOnboardingTour()` 호출하므로 재시작은 되지만, 투어 진행 중 "다시 보지 않기"를 누르면 다시 `localStorage.setItem`이 되므로 ❓ 버튼을 다시 눌러야 함 — 이것이 의도한 동작인지 확인. 사용자가 혼란할 수 있으므로 "다시 보지 않기" 클릭 후 ❓ 버튼에 시각적 안내(펄스 애니메이션 등)를 표시하는 것 검토.
4. **i18n 번역 확장** — 현재 주요 키만 다국어 번역됨. AI 패널, 설치 위자드 등의 번역을 34개 언어 전체로 확장 필요.
5. **RTL 레이아웃** — 아랍어/우르두어/페르시아어 선택 시 UI 방향 전환 (현재 플래그만 표시)
6. **Git 커밋** — 현재 변경사항 미커밋 상태
7. **Sheet 강화**: 셀 병합, 차트, 조건부 서식
8. **Slide 강화**: 애니메이션, 전환 효과, 도형 삽입
9. **Document 강화**: 목차 자동 생성, 페이지 번호, 머리말/꼬리말
10. **PDF 강화**: 주석/하이라이트, 폼 필드
11. **HWPX 강화**: 이미지/표 지원 강화
12. **PPTX/DOCX 가져오기/내보내기**

## 총평
이번 세션에서 MarkLink SL은 "마크다운 에디터"에서 "글로벌 무료 오피스 대안"으로 도약하는 핵심 기능들을 갖추었다. 34개 언어 지원 + IP 기반 자동 추천 + 첫 사용자 온보딩 투어로 전 세계 사용자, 특히 유료 오피스를 구매하기 어려운 개발도상국 사용자들의 진입 장벽을 크게 낮추었다. AI 기능의 Vision 모델 지원으로 PDF 수식/표/이미지 분석까지 가능해져 학술·교육 분야에서의 활용도가 높아졌다.
