## 작업 요약
PhotoLink 에디터에 6개 프로 수준 기능 추가: Split Toning UI, Selective Color/Color Splash, Before/After Split View, Real-time RGB Histogram, Clone/Stamp Tool, Spot Healing Tool.

## 주요 결과물
- `index.html` — 새 toolbar 버튼 6개(Clone, Heal, Split, Hist) + Split Toning 패널 + Color Splash 패널 + canvas overlay 요소들
- `src/photo/photo-editor.js` — 1622→2224줄. 6개 신규 기능 함수 추가
- `src/styles/photo.css` — Color splash 버튼, clone bar, split view label 스타일

## 핵심 결정사항
- Split Toning: color picker → hexToHue 변환으로 WebGL splitToning params에 매핑
- Color Splash: 8 hue 버튼 토글 방식, preserveHueRanges로 WebGL selectiveColor에 전달
- Split View: clipPath 기반 before/after 비교 (별도 before canvas에 원본 캡처)
- Histogram: 512px 다운샘플링 후 R/G/B/Luminance 채널 오버레이
- Clone: Alt+click 소스 설정 → 원형 브러시로 클론 (getImageData 기반)
- Spot Heal: smoothstep 블렌딩 + 주변 링 텍스처 평균으로 자동 채움
